🤖 RAG Algorithms Examiner - הסבר כללי
RAG Algorithms Examiner הוא בוט לימודי אינטליגנטי המבוסס על סוכני AI, שנועד לסייע לסטודנטים לשלוט בחומר הקורס "אלגוריתמים". המערכת משתמשת בטכנולוגיית RAG (Retrieval-Augmented Generation) ובספריית LangGraph לניהול לוגיקה מורכבת של למידה מותאמת אישית.

🛠 ארכיטקטורה טכנית
המערכת בנויה משלושה רכיבי ליבה:

Vector Database: אחסון חומרי הקורס, פסאודו-קוד והוכחות סיבוכיות.

RAG Engine: שליפת המידע הרלוונטי ליצירת שאלות, רמזים וסיכומים.

LangGraph Orchestrator: ניהול ה-Workflow באמצעות Conditional Edges וצמתים (Nodes) המייצגים שלבים שונים בתהליך הלימודי.
